# Инструкция по деплою на GitHub Pages

## 🚀 Быстрый деплой

### Шаг 1: Добавить все изменения в Git

```bash
# Добавить все измененные и новые файлы
git add .

# Создать коммит с описанием изменений
git commit -m "Обновление проекта: добавлены все практики 19-26"

# Отправить изменения на GitHub
git push origin main
```

### Шаг 2: Деплой на GitHub Pages

```bash
# Собрать проект и задеплоить на GitHub Pages
npm run deploy
```

Эта команда:
1. Соберет проект (`npm run build`)
2. Загрузит папку `dist` в ветку `gh-pages` на GitHub
3. Ваш сайт будет доступен по адресу: `https://qihed.github.io/frontiback/`

---

## ⚙️ Настройка GitHub Pages в репозитории

После первого деплоя нужно настроить GitHub Pages:

1. Перейдите в репозиторий на GitHub: https://github.com/qihed/frontiback
2. Откройте **Settings** (Настройки)
3. В левом меню найдите раздел **Pages**
4. В разделе **Source** выберите:
   - **Branch**: `gh-pages`
   - **Folder**: `/ (root)`
5. Нажмите **Save**

Через несколько минут ваш сайт будет доступен по адресу:
**https://qihed.github.io/frontiback/**

---

## 📝 Важные замечания

### Если репозиторий называется по-другому

Если ваш репозиторий называется не `frontiback`, нужно изменить `base` в `vite.config.js`:

```js
base: '/название-вашего-репозитория/',
```

### Если это корневой репозиторий пользователя

Если ваш репозиторий называется `username.github.io` (например, `qihed.github.io`), то в `vite.config.js` установите:

```js
base: '/',
```

### Обновление сайта

После каждого изменения кода выполните:

```bash
git add .
git commit -m "Описание изменений"
git push origin main
npm run deploy
```

## 🔧 Ручной деплой (альтернатива)

Если команда `npm run deploy` не работает, можно выполнить вручную:

```bash
# Собрать проект
npm run build

# Перейти в папку dist
cd dist

# Инициализировать git (если еще не инициализирован)
git init

# Добавить все файлы
git add .

# Создать коммит
git commit -m "Deploy to GitHub Pages"

# Добавить удаленный репозиторий (если еще не добавлен)
git remote add origin https://github.com/qihed/frontiback.git

# Отправить в ветку gh-pages
git push -f origin main:gh-pages
```

## 🐛 Решение проблем

### Проблема: Сайт показывает 404 или пустую страницу

**Решение**: 
- Проверьте, что `base` в `vite.config.js` соответствует названию репозитория
- Убедитесь, что в настройках GitHub Pages выбрана ветка `gh-pages`

### Проблема: Статические ресурсы не загружаются

**Решение**: 
- Проверьте `base` в `vite.config.js`
- Убедитесь, что все пути к ресурсам относительные (начинаются с `/` или `./`)

### Проблема: React Router не работает

**Решение**: 
- Убедитесь, что `base` настроен правильно
- Проверьте, что все ссылки используют `Link` из `react-router-dom`, а не обычные `<a>` теги
