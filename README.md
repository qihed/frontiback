# Frontend и Backend разработка - Практические занятия
https://qihed.github.io/

Проект содержит реализацию практических занятий по фронтенд и бэкенд разработке на React. Каждая практика демонстрирует различные концепции и техники работы с React.

## 🎯 О проекте

Проект представляет собой **Трекер технологий** - полнофункциональное React-приложение для отслеживания прогресса изучения различных технологий. Все практические задания (19-26) интегрированы в единое приложение с роутингом, авторизацией и современным UI.

### Основной функционал:
- 📚 Управление списком технологий с различными статусами (не начато, в процессе, изучено)
- 📊 Отслеживание прогресса изучения с визуализацией
- 📝 Добавление заметок и дедлайнов к технологиям
- 🔍 Фильтрация и поиск технологий
- 💾 Сохранение данных в localStorage
- 📥 Импорт/экспорт данных в JSON формате
- 🎨 Современный UI с Material-UI компонентами
- 🔐 Базовая авторизация и защищенные маршруты
- 🌐 Работа с внешними API

## 🚀 Запуск проекта

### Установка зависимостей

```bash
# Установка основных зависимостей
npm install

# Установка Material-UI (для Практики 26)
npm install @mui/material @emotion/react @emotion/styled @mui/icons-material

# Установка React Router DOM (для Практики 23)
npm install react-router-dom
```

### Команды разработки

```bash
# Запуск сервера разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен сборки
npm run preview
```

### Основные зависимости

- **React** - библиотека для создания пользовательских интерфейсов
- **React Router DOM** - маршрутизация и навигация в приложении
- **Material-UI (@mui/material)** - библиотека компонентов для React
- **Vite** - инструмент сборки и разработки

- **React Router**: Реализована полноценная навигация с защищенными маршрутами и динамическими параметрами
- **Кастомные хуки**: Созданы переиспользуемые хуки (`useLocalStorage`, `useTechnologies`, `useApi`) для инкапсуляции логики
- **Material-UI интеграция**: Использованы компоненты Material-UI для улучшения UX (Dialog, Snackbar, Theme)
- **Работа с API**: Реализован хук `useApi` с поддержкой debounce и AbortController для отмены запросов
- **Локальное хранилище**: Все данные технологий сохраняются в `localStorage` с автоматической синхронизацией
- **Импорт/Экспорт**: Поддержка экспорта в JSON, импорта из файлов и drag-and-drop функциональности
- **Валидация форм**: Реализована валидация с отображением ошибок в реальном времени
- **Обработка ошибок**: Везде реализована обработка ошибок с понятными сообщениями для пользователя
- **Доступность**: Учтены требования доступности (ARIA-атрибуты, семантическая разметка)
- **Комментарии**: Все компоненты содержат подробные комментарии с пометкой **"НОВОВВЕДЕНИЕ"** для обозначения новых концепций

## 🎯 Основные концепции React, используемые в проекте

- **Компоненты и Props** (Практика 19) - создание переиспользуемых компонентов
- **useState Hook** (Практика 20) - управление состоянием компонентов
- **useEffect Hook** (Практика 21) - побочные эффекты и жизненный цикл
- **Кастомные хуки** (Практика 22) - создание переиспользуемой логики (`useLocalStorage`, `useTechnologies`)
- **Обработка событий** (Практика 22) - формы, валидация, события браузера
- **Работа с массивами** (Практика 23) - CRUD операции, фильтрация, маппинг
- **React Router** (Практика 23) - маршрутизация, навигация, защищенные маршруты
- **Условный рендеринг** (Практика 24) - динамическое отображение контента
- **Работа с внешними API** (Практика 24) - кастомный хук `useApi`, debounce, AbortController
- **Работа с браузерными API** (Практика 25) - localStorage, FileReader, Blob, drag-and-drop
- **Интеграция сторонних библиотек** (Практика 26) - Material-UI компоненты, темизация
